下表是目前採用的陣營基準版。只列主要成員，**不是結局**：日內瓦大會上陣營會重組，出席者依這張表決定，見 [日內瓦信仰大會](geneva-conference.html)。

| 陣營 | 主要成員 |
| --- | --- |
| 天主教聯盟（法國主導，教廷為精神領袖） | 法國、波蘭路線 A 到 D、愛爾蘭 A、奧地利神羅正統與天主教奧地利王國、勃艮第公國、亞拉岡王國（卡洛斯派）、巴伐利亞天主教王國、馬爾他騎士團、安道爾、列支敦斯登、勞倫提亞、瓜達盧佩。法國走路線 B 或 D 時與神羅分道揚鑣，但聯盟本身不解散 |
| 騰格里同盟（草原天之鞭） | 匈牙利路線 1、保加利亞路線 A、土耳其路線 A、大平原汗國（同盟或對決二選一）；匈牙利路線 2 與保加利亞是「歐諾古爾兄弟」 |
| 凱爾特聯盟 | 愛爾蘭 B、格溫內斯、康瓦爾、布列塔尼、曼島 B；與法國結盟的條件是保障國內天主教 |
| 北方聯盟 | 米德加爾特（卡爾馬路線 A）、普通卡爾馬聯盟（B）、薩米王國（C、D）；冰島與法羅群島若加入 |
| 佛教與東方圈 | 大梵天德意志金剛神國、西藏（藩屬）、日耳曼靜默黑天神國；與大明（葡萄牙）、毗濕奴王國互有往來，但不成同盟 |
| 共產與無神 | 蘇聯、義大利人民共和國、西班牙共產黨 |
| 猶太陣營 | 猶太國度各路線與白俄羅斯猶太國（結盟）；與德國、波蘭、羅馬尼亞各路線敵對 |
| 黑大西洋 | 牙買加、海地、古巴、普林斯霍爾 |
| 無陣營 | 瑞士（日內瓦大會主辦國）、麥克阿瑟的美利堅（北美的正常人） |
