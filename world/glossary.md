企劃裡反覆出現的詞，在這裡統一說明。每一條都已確認，詳細內容請看連到的頁面。

## 分級與符號

| 詞 | 意思 |
| --- | --- |
| A 級 | 多路線的國家，有重點設計的各條路線與領土宣稱、開戰事件。見 [全國路線總表](country-roster.html) |
| B 級 | 單路線的國家，有一條特殊路線 |
| C 級 | 沒有特殊路線的國家，只有事件包或一般內容 |
| ★ | 「正常人」標籤：在荒誕世界裡仍然走史實與理性路線的國家，例如法國、麥克阿瑟的美利堅 |
| ◇ | 分裂產物：由內戰或分裂產生的新國家 |
| 待查證 | 史實部分是憑記憶寫的，還沒有逐條核對；寫進事件之前要再查證 |
| 路線代號 | A、B、C 等代號是歷史演進留下的，不一定連號（例如蘇聯沒有 B）；實作前會統一重編 |

## 世界機制

| 詞 | 意思 |
| --- | --- |
| 信仰大戰 | 世界大戰的名稱。緊張度達標，或到保底日期（1940 年 2 月 29 日），先到者為準；玩家可以選擇不參戰。見 [世界大戰](world-war.html) |
| 日內瓦信仰大會 | 1938 年秋，瑞士以布威蒂教為國教，邀請各宗教國度的領袖開大會；陣營在這裡重組。見 [日內瓦信仰大會](geneva-conference.html) |
| 至高羅馬最終對決 | 1941 年底，有三個以上「宣告羅馬」的國家時觸發；7 個以上是超級版。見 [至高羅馬最終對決](supreme-rome.html) |
| 先搶先贏（競爭宣稱） | 多國搶同一塊地時，誰先觸發誰先拿，其他路線變成「競爭宣稱」；爭搶時自動獲得對現任擁有者的宣稱。見 [領土重疊宣稱表](claims-overlap.html) |
| 古王宴 | 「古王歸來」的國家之間的承認機制；**不做** |
| 費城決裂 | 1938 年 7 月 4 日，美國分裂 |
| 世界衝突列表 | 全世界的 80 場衝突（K01 到 K80），含參與方、爭什麼、怎麼打。見 [世界衝突列表](conflicts.html) |
