## 卡爾馬聯盟（玩家選擇聯盟後有四條路線）

| 路線 | 內容 |
| --- | --- |
| A | 以北歐神話維京信仰為主的宗教國家，**米德加爾特王國**。唯有向米德加爾特稱臣者可去阿斯嘉。可納入挪威、瑞典、芬蘭、卡累利阿、愛沙尼亞等。決議：【從瓦良格到拜占庭】、【從諾斯到文蘭】、【控制英吉利】。可沿聶伯河南下，建立魁儡基輔羅斯與諾夫哥羅德公國；可征服冰島、法羅群島（或它們早已加入）、格陵蘭與北美沿岸。芬蘭與卡累利阿也可選擇加入匈牙利的聯盟 |
| B | 普通的卡爾馬聯盟，聯合丹麥 |
| C | 薩米人南下奪權：聯盟剛成立時突襲首都（挪威主導就是奧斯陸，瑞典主導就是斯德哥爾摩），建立包括挪威、瑞典、芬蘭、卡累利阿、科拉半島的**薩米王國**。以薩米巫覡薩滿信仰為國教，並借 1927 年芬蘭國家廣播公司「馬爾庫斯叔叔」的說法，國家領袖稱**聖誕老公公**，用來合理化對基督徒的統治 |
| D | 薩米人的馴鹿在睡覺，沒有南下突襲。薩米王國只獨立於北邊。卡爾馬聯盟可選擇討伐或不理會，並與薩米王國一同東征 |

## 芬蘭

- 烏闊與卡勒瓦拉（史實上 1835 年編纂的國家史詩）的異教復興。
- 大芬蘭（東卡累利阿；1929 到 1932 年有拉普阿運動）。
- 加入北歐或加入匈牙利路線 2。

## 其他

- **格陵蘭**是北歐與北美唯一的接點（米德加爾特、溫迪哥、丹麥），見 [北美總覽](../north-america/overview.html)。
- **芬蘭、卡累利阿的歸屬**被米德加爾特、匈牙利路線 2、薩米王國同時宣稱：**競爭宣稱**，見 [領土重疊宣稱表](../world/claims-overlap.html)。

## 補充

- **丹麥、瑞典、挪威**不選卡爾馬聯盟時也要加入其他路線，細節之後設計（使用者要求）。冰島、法羅群島與格陵蘭的處理併入同一批設計。

## 補充

| 國家 | 路線 |
| --- | --- |
| 丹麥 | DK1．克努特的北海帝國（史實 1016 到 1035 年同時統治丹麥、英格蘭與挪威；宣稱英格蘭東部的丹麥法區與挪威）；DK2．新教聯盟的海峽守衛者（控制松德海峽，加入新教與清教圈）；DK3．南日德蘭保衛戰（與威廉二世復辟後的德意志爭北石勒蘇益格） |
| 瑞典 | SE1．北方之獅（古斯塔夫二世·阿道夫的新教軍事強國，領導新教與清教圈，與天主教聯盟形成三十年戰爭重演）；SE2．斯威登堡新教會（以神祕學為國教的中立國，與通靈聯邦呼應）；SE3．烏普薩拉的神廟（加入米德加爾特，作為不選聯盟時的出口） |
| 挪威 | NO1．永恆之王聖奧拉夫（奧拉夫神權王國，尼達羅斯大教堂是聖地）；NO2．吉斯林的挪威（民族統一黨，一個「正常人」的法西斯路線）；NO3．南極與捕鯨（捕鯨艦隊帝國，南極宣稱） |
| 冰島 | A．加入米德加爾特；B．與丹麥聯合維持（1940 年起可要求修訂聯合法，待查證）；C．獨立中立（1930 年阿爾庭千年慶典） |
| 法羅群島 | 北歐神話信仰的路線（隨丹麥或米德加爾特的事件仍保留） |
| 格陵蘭 | 因紐特人聯合帝國的「綠色大地」路線；歸屬事件由米德加爾特、丹麥、溫迪哥三方 |

- **新增「新教與清教圈」**陣營，見 [信仰陣營](../world/factions.html)。
- **英格蘭東部（丹麥法區）**由新愛西尼、米德加爾特與丹麥 DK1 同時宣稱，適用競爭宣稱。

## 米德加爾特的蜜酒廳路線

- 米德加爾特（卡爾馬路線 A）**多一條路線：蜜酒廳（Mead Hall）**——建立中央蜜酒廳，作為世界權力的象徵，同時開啟控制**漢薩同盟城市**的貿易大國。

## 補充

- **奧克尼與昔得蘭**可由法羅群島或蘇格蘭併吞（由事件機制決定）。
