## 五條路線

| 路線 | 內容 |
| --- | --- |
| A | 拜占庭帝國復辟。恢復君士坦丁堡牧首地位，取代莫斯科牧首；是【至高羅馬最終對決】的參賽者，見 [至高羅馬最終對決](../world/supreme-rome.html) |
| B | 重建萬神殿。僭主統治，底下有十三人僭主集團進行人民審判，實施陶片放逐法。希臘神話為國教，不信神違法，可處決。祭典與運動會為國家明文儀式 |
| C | 恢復偉大理想（Megali Idea）：佔領東色雷斯、拜占庭、愛奧尼亞。與 A 一樣維持正教，牧首地位同 A |
| D | 近似 B，宗教更強：重建神廟，大祭司統治，國名**奧林帕斯神國**。宣布結束工作與時日的黑鐵時代，重返英雄時代，最終過渡到黃金時代 |
| E | 柏拉圖理想國：哲學家專制，領袖由定期辯論大會選出，教育由國家絕對掌控，「正義」是唯一方針 |

## 與鄰近的關係

- **賽普勒斯**：史實 1931 年有併希臘暴動，希臘 A、C 路線自然想要；英國內戰時歸屬變成事件，見 [英國](britain.html)。
- **法國**：希臘 A（拜占庭）是法國路線 D、E 的對手與盟友：法國與希臘議和聯姻是「第二次的查理曼與伊琳娜」，見 [法國](france.html)。
- **土耳其**：土耳其 A 的太陽語言理論把愛琴海沿岸當「突厥的本土」，與希臘各路線衝突；土耳其 B（哈里發）與希臘 A（拜占庭）爭「君士坦丁堡」的正統；土耳其 C（世俗）與希臘 C（偉大理想）爭色雷斯，但 C 對 C 以蒙特勒公約（1936 年）外交解決為預設。其他組合沒有特別事件。
- **色雷斯與君士坦丁堡**由希臘 A／C、大色雷斯、土耳其路線同時宣稱，適用競爭宣稱。
- **愛奧尼亞群島與多德卡尼斯群島**的事件見 [微型國家與歐洲小地方](microstates.html)。

## 克里特

- 希臘走 B、D、E 路線時，克里特島也可能獨立，成為**米諾斯海上王國**（B 級）：米諾斯王的迷宮與牛頭人、線形文字 A、海上霸權；與**賽普勒斯**爭奪邁諾斯文明的正統，兩者都強制使用線形文字 A；**克里特也可以選擇加入西西里城邦聯合**（見 [義大利](italy.html)）。
