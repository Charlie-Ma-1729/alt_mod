## 有自己路線的小國與地區

| 國家與地區 | 級別 | 路線 |
| --- | --- | --- |
| 安道爾 | B | **雙親王之國**：為支持天主教，法國讓烏赫爾主教獨立統治，取得烏赫爾教區的宣稱與核心；烏赫爾主教與法國共同親王（待查證）兩個頭一起簽名才有效，機制是「簽名僵局」 |
| 盧森堡 | B | **美露西娜之國**：創建傳說是齊格弗里德伯爵與水妖美露西娜（待查證）；拒絕神羅、法國、勃艮第三方爭搶，妖精水妖的獨立小公國；可以宣稱薩爾與比利時的盧森堡地區，成為**大盧森堡**；夏洛特大公得選邊，見 [比利時、荷蘭、盧森堡](benelux.html) |
| 列支敦斯登 | A | **最後的諸侯**：宣稱自己是「神聖羅馬帝國最後的諸侯」，神羅復辟的第一天宣誓效忠（史實上它確實是帝國諸侯國的後裔）。兩條路線：奪取神聖羅馬領袖地位；奇襲瑞士，或支援被瑞士衛隊挾持的宗教大會（只在瑞士走獨裁時出現） |
| 馬爾他 | B | 聖約翰騎士團復歸，主權軍事修會國，是法國 E 十字軍帝國的「騎士團槓桿」之一，海軍強 |
| 梵蒂岡＝教宗國 | A | 義大利 C 時取得大量領土、召開第二十一屆大公會議；義大利 A、B 時在亞維儂流亡，見 [教廷](../world/papacy.html) |
| 摩納哥 | B | **輪盤神教**，賭場是國教；格里馬迪家族，與法國有條約，法國帝國下是保護國，法國崩潰時是金融中立區（像倫敦） |
| 直布羅陀 | B | **巴巴里獼猴公國**（傳說猴子離開則英國失去直布羅陀，待查證）；歸屬見 [英國](britain.html) |
| 法羅群島 | A | 北歐神話信仰，三條路線：獨立；加入米德加爾特；以法羅群島為中心建立**維京傳奇海上帝國** |
| 格陵蘭 | B | 國名**卡拉利特努納特**（Kalaallit Nunaat，意為「人類之地」，待查證），因紐特人聯合帝國，建立**冰宮**；海洋哺乳動物神薩德娜、北極光、跨極地因紐特聯盟 |
| 賽普勒斯 | B | 與克里特爭邁諾斯文明正統，強制使用線形文字 A，也可以選擇加入西西里 |
| 聖馬利諾 | C | 沒有特殊路線，最古老的共和國，義大利分裂時選邊的彩蛋事件 |

## 歐洲小地方

不能讓它空著，全部做成事件，不做國策樹：

| 地方 | 宣稱者與鉤子 |
| --- | --- |
| 但澤自由市 | 國際聯盟託管，1933 年起納粹參議院執政。宣稱者：德國各路線、波蘭各路線、條頓騎士團（史實上 1308 到 1454 年屬騎士團國） |
| 美美爾（克萊佩達） | 立陶宛的自治區，德國人口多，史實上 1939 年被德國併吞。宣稱者：立陶宛、德國、條頓騎士團 |
| 菲烏梅（里耶卡） | 鄧南遮 1919 到 1920 年的詩人攝政國「卡爾納羅攝政」，鄧南遮 1938 年 3 月過世（待查證）。宣稱者：義大利分裂各方、南斯拉夫各方、威尼斯商團；事件：鄧南遮的追隨者重建攝政 |
| 多德卡尼斯群島（義大利屬） | 希臘各路線、土耳其、馬爾他騎士團（1310 到 1522 年統治羅得島） |
| 愛奧尼亞群島（科孚） | 希臘、威尼斯商團、義大利（1923 年科孚事件） |
| 唐努圖瓦 | 史實上 1921 到 1944 年的獨立國；宣稱者：蘇聯各路線、奧茲蒙古、紅色香巴拉路線 |
| 奧蘭群島 | 芬蘭、瑞典、米德加爾特 |
| 斯瓦爾巴與熊島 | 挪威、蘇聯 |
| 北石勒蘇益格 | 丹麥、德國 |
| 切申 | 波蘭、猶太捷克 |
| 薩爾 | 1935 年回歸德國（史實）；只是小摩擦，**不當二戰導火線**；盧森堡也可以宣稱薩爾與比利時的盧森堡地區，成為**大盧森堡** |
