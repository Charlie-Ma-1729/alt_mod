| A | 東正教天使長米迦勒軍團（鐵衛團） |
| B | 札爾莫克西斯復興（達契亞異教） |
| C | 格拉西姆·盧卡在外西凡尼亞（錫比烏附近）找到蒼白高大的老人，宣稱是未死（或復活）的**穿刺公弗拉德三世**。鐵衛團找來米爾恰·伊利亞德合作，政變逼卡羅爾二世承認並放棄君主專制。穿刺公成為大羅馬尼亞王國**黑夜之王**；羅馬尼亞是「高貴英勇的吸血鬼英雄」，要剷除真正危害人類的妖怪：被嗜血匈奴惡魔附身的匈牙利、淪為屍骸的保加利亞（塞爾維亞人、匈牙利人等被 Strigoi 與 Vârcolac 威脅） |
| D | 同 C，但卡羅爾二世拒絕放棄專制，刺殺盧卡，把老人帶到布加勒斯特。伊利亞德遊說鐵衛團，在見證下卡羅爾二世飲下穿刺公的血，成為永生吸血鬼之王，稱黑夜之王，立場同 C |
| E | 羅馬尼亞改變羅姆人政策（強迫定居、語言同化），羅姆人總聯盟領袖喬治·尼古列斯庫態度溫和，被刺重傷。迫於壓力與分道揚鑣的格奧爾基·拉扎雷努-拉祖里卡合作，在外西凡尼亞建立**羅姆斯坦**，拉祖里卡自封吉普賽人之王，持續法西斯集權，但改為抨擊正教與同化政策。可與庫班、烏克蘭東部獨立的羅姆民族主義者米哈伊爾·季莫費耶維奇·別茲柳德斯基結盟。以羅姆人傳統信仰為國教 |
