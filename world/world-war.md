## 基本設定

- **要有一場世界大戰**，名稱「**信仰大戰**」；官方開始日就是第一槍事件日。使用者的方向：有重點設計的 **A 級國家與陣營**，會依照各自的路線，在國策裡有各自的**領土宣稱**與**開戰事件**。
- 不是純沙盒，也不是所有人自動大亂鬥：戰爭由各條路線的宣稱與事件一路推上去。「A 級」的定義見 [總覽](overview.html)；陣營見 [信仰陣營](factions.html)。
- **陣營不整併**成兩三大陣營；但可以出現「A 陣營與 B 陣營同時都在打 C 陣營」這類戰爭型態。**遠方戰區的 AI 可以優化**（降級成簡化事件）。
- 三層結構：戰區層（各路線事件自己把戰區推向戰爭）、陣營層（日內瓦之後陣營重組，成員可以互相拉入）、保底層（避免一直壓著緊張度不打）。
- **玩家可以不參戰**：玩家可以選擇自己控制的國家不參戰。每個國家會有國策強制宣戰或獲得正當化宣稱，但本來就可以選擇不點。
- **參考**：KX 模組的黑色星期一；KX 的世界大戰是第三國際對帝國公約、協約國反攻；史實有大蕭條與同盟國對軸心國的明確陣營戰爭。本模組不要求世界一定分幾派陣營，但要避免世界只剩內戰與各方小規模戰鬥、沒有貫穿全世界的大戰。

## 第二次世界大戰怎麼開始

- **定義**：只要**德國跟法國開戰**，不管用任何方法，就是第二次世界大戰。
- **只有「主要導火線」的戰爭才能作為二戰**，沒有列為主要導火線的戰爭都不算二戰。
- **主要導火線**：若二戰尚未開打，觸發後該戰爭就是二戰的**第一槍，二戰即刻開始**。**次要導火線**：僅增加緊張度。「前奏」等於次要導火線。
- **觸發方式與保底**：緊張度達標，或到保底日期（**1940 年 2 月 29 日**），先到者為準；日內瓦大會破局增加緊張度。保底日到了還沒開打，觸發「國家危機」事件：不應戰就政變，由繼任政府宣戰；兩邊都拒絕時，以緊張度貢獻較大的一方為準。緊張度（0 到 100）用作「德法危機」的進度條：25 邊界與萊茵蘭事件；50 最後通牒；75 動員；100 或保底日期開戰。

| 萊茵蘭、巴登、美茵茲叛亂 | 與巴伐利亞同樣處理，同為主要導火線 |
| 阿爾薩斯－洛林收復 | 德國路線 6（威廉二世復辟）；KX 同款的明確開戰事件 |
| 法國路線 D 的中法蘭克進攻 | 全羅馬人帝國向德國西部（中法蘭克）宣戰 |
| 法國路線 E 的十字軍 | 對佛教德國（德國路線 1）宣布十字軍 |
| 日內瓦的夜 | 瑞士走布威蒂獨裁路線時；**只有開戰雙方都是【與會大國】才是主要導火線**，否則是次要導火線；機制見 [日內瓦信仰大會](geneva-conference.html) |
| 奧地利（神羅正統路線） | 德國下最後通牒，接著與奧地利開戰併吞；若同時爆發南方天主教叛亂，法國加入奧地利（神羅）方，戰爭進行中法國加入則成為主要導火線。奧地利若是奧匈二元帝國路線，德國無法德奧合併 |

| 但澤與波蘭走廊 | 史實的第一槍；法國保證波蘭 |

**次要導火線**（只加緊張度）：日內瓦大會破局；貨幣戰爭與經濟封鎖；英國內戰的外國介入（倫敦陷落）；亞洲與中東的事件（日本侵華、武林大會、高加索戰爭、西奈聖戰、約櫃之戰、石油雙雄）；北美與太平洋的事件（德州、夏威夷、太平洋、印度崩解、英國殖民地 1940）。

**不作為導火線**：薩爾（只是小摩擦，見 [微型國家與歐洲小地方](../europe/microstates.html)）；德國趁法國內亂收復（德國沒有好的開戰理由）；多瑙河大劫難；瑞士邊境事件與列支敦斯登奇襲（併入日內瓦的夜）；美美爾與立陶宛；條頓騎士團與東普魯士；普羅米修斯計畫；義大利分裂與教宗被逐；義大利路線 C 的教宗國；西班牙內戰國際化。至高羅馬宣告（1941 年底）維持為二戰之後的第二次高潮，不當導火線。

## 保證獨立（保獨）

- **法國不管走哪條路線，都會保證波蘭、奧地利（天主教）、勃艮第的獨立**，所以德國打這些國家就會開戰。
- **1939 年以前不能自由保獨國家**：只有上面這份預設的保證。
- **蘇台德**：和平吞併蘇台德失敗而爆發戰爭時，捷克若輸了也只會丟蘇台德；法國沒有保證捷克猶太國，所以德法不會因此開戰。
- **義大利與德國**：義大利社會共和國 A、B 可以與德國希姆萊、戈培爾路線結盟；其他德國路線沒有。
