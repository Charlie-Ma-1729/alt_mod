## 原則

- **北美以歐洲設定為主，配合歐洲**；北美事件寫成條件式（例如英國內戰發生，加拿大才分裂）。
- 英國六方內戰、葡萄牙大明：以歐洲那邊為準，北美不處理。
- 法國在北美是「天主教聯盟的後援」，不用「極端」。
- **玩家開局選 A**：政變強制發生，前十個月是正常的美國，之後分裂，玩家選擇扮演哪一方。
- **分級**：先照 A/B/C 三級，**但每個國家都要有一條專屬國策樹（小國可短）**。名單（使用者回答「先照三級」）：
  - A 級（完整國策樹）：聯邦憲政派、普林斯霍爾、洪門、原住民、德撒律、墨西加、瓜達盧佩、勞倫提亞、通靈聯邦。
  - B 級（共用小樹加事件）：「我是」帝國、狄凡恩、迦樓羅、哭泣十字、海地、牙買加、古巴、多明尼加。
  - C 級（只有事件和彩蛋）：溫迪哥、海盜聯盟。
- **現存宗教**（摩門教、拉斯塔法里、巫毒、桑特里亞、原住民信仰、「我是」運動）：保持荒誕但以真實歷史事件為主，尺度放寬。
- **歐洲殖民地**由母國路線決定；**格陵蘭**是北歐與北美唯一的接點。
- 西班牙、墨西哥、古巴的連動：等西班牙內戰結果再說。

## 新增的決定

- **條件式連動表**（採用）：
  - 英國內戰發生 → 加拿大分裂；沒發生 → 加拿大維持，迦樓羅等不出現。
  - 義大利教宗逃亡 → 勞倫提亞與憲政派內的天主教徒有反應。
  - 西班牙內戰結果 → 瓜達盧佩與古巴的連動事件。
  - 日內瓦信仰大會 → 北美各勢力搶美國席位。
  - 格陵蘭 → 北歐與北美唯一的接點（米德加爾特、溫迪哥、丹麥）。
  - 大平原汗國 → 和匈牙利（騰格里）連動，**同盟或對決二選一**；亞洲階段與蒙古連動**存疑**（亞洲大機率不會依史實）。
- **美國的名字**：「美利堅合眾國」留給麥克阿瑟的殘存政府，憲政派改名「聯邦憲政天朝」，見 [美國](usa.html)。
- **洛聖都、罪惡都市、自由城取消**，不做這三座城市國家。
- **美國小項**：不要太複雜，能併入既有勢力就併（見 [美國](usa.html)）。
- **黑大西洋會議**：細節之後定。

## 原案對歐洲的描述（僅供對照，以歐洲設定為準）

- 英國：愛德華八世拒絕退位自立為印度皇帝，成立不列顛毗濕奴聯合王國，倫敦與德里雙首都；隨後本土**六方內戰**：毗濕奴王國、斯圖亞特蘇格蘭、新愛西尼王國（新布狄卡女王）、格溫內斯王國（德魯伊威爾斯）、康瓦爾公國、威賽克斯王國（亞瑟王阿瓦隆回歸）。
- 德國：黨衛軍西藏考察團帶回神秘傳承，國家體制轉向藏傳佛教密宗化。
- 法國：推翻世俗共和，成為正統極端天主教宗座保衛國。
- 匈牙利：阿提拉轉世降臨，重歸長生天。
- 葡萄牙：明朝嘉靖二世正統皇室流亡至里斯本，建立大明流亡法統。

## 補充

- **三座城市取消後**的位置就近配給各勢力（紐約歸憲政天朝、洛杉磯歸洪門、邁阿密與佛羅里達由麥克阿瑟的美利堅與古巴爭奪），見 [美國](usa.html)。
- **「我是」帝國**改寫成廣播與電力的神權，沒有武器，見 [美國](usa.html)。
- **美國小項**併入既有勢力，見 [美國](usa.html)。
- **黑大西洋會議**採用（依後續設定調整），見 [加勒比海](caribbean.html)。
