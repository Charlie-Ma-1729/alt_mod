## 法蘭西第三帝國（路線 A：原案）

- 觸發：1936 年人民陣線（6 月布魯姆內閣上台）引發右翼危機，火十字團（領袖拉羅克）與保王派結合。奧爾良家（家主吉斯公爵讓，1874 年生）與拿破崙家（路易·拿破崙，1914 年生）達成協議，推翻共和。
- 路易·拿破崙 22 歲，是**皇帝**。實權在**奧爾良攝政議會**：議席**世襲**，由吉斯公爵領導，繼承人是巴黎伯爵亨利（1908 年生）。
- 國號暫定**法蘭西第三帝國**（接續拿破崙三世的第二帝國）。
- **主教制度**：設立「主教院」，對法律有否決權，確保天主教不偏離，教宗庇護十一世支持。
- **天主教聯盟**拉攏：波蘭、比利時、愛爾蘭，奧地利若走神羅正統也加入。
- 宣傳口號：**舊世界最後防線**（因為其他國家都各自會有奇怪路線）。
- **天主教作為舊世界最後堡壘不變**。

## 政教政策

- 法國的決策改成「**恢復 1801 年教務協定**」與「**廢除費里法（1880 年代學校世俗化）與 1904 年禁止修會授課的法律**」。波拿巴家恢復祖先簽的條約，主教院的法理基礎也由此而來。
- 阿爾薩斯－洛林在法國與神羅的爭奪中，是「這裡一直守著教務協定」的象徵（阿爾薩斯－摩澤爾史實上從未適用 1905 年政教分離法）。

## 凱爾特聯盟與布列塔尼

- 凱爾特聯盟成立並影響法國時，法國可談判讓**布列塔尼公國獨立**，換取凱爾特聯盟國家加入法國的聯盟。
- 若愛爾蘭（也可能領袖是威爾斯，愛爾蘭沒加入）拒絕談判，可選擇直接讓布列塔尼獨立避免戰爭，或開戰。
- **「持平」的意思**：凱爾特聯盟的愛爾蘭、威爾斯、康瓦爾等地是**德魯伊為主、天主教為輔**。這些國家若要與法國結盟、並讓布列塔尼的民族主義獨立，**必須保障國內天主教勢力**。法國自己不變，仍只有天主教。
- 安道爾由烏赫爾主教獨立統治，見 [微型國家](microstates.html)。

## 法國路線 A 到 F

| 路線 | 內容 |
| --- | --- |
| A | 原本所討論的路線（上面） |
| B | 波旁王朝撕毀烏特勒支和約（1713 年，腓力五世及其後代放棄法國王位）的相關條款，要求正統的王冠，以此契機**法西合併**。這條路線使法國與神羅分道揚鑣 |
| C | 法國將自身皇室與古高盧凱爾特領袖連結，復興、宣傳高盧的史詩和故事，在以天主教為主打的前提下，建立**凱爾特民族主義的高盧帝國**。可直接與凱爾特聯盟的國家結盟，並成為領導者 |
| D | 法國將自身皇室與查理曼和法蘭克王國連結，獲得過去整個法蘭克王國領土的宣稱，國號改為**全羅馬人帝國**。與 B 一樣會使法國與神羅分道揚鑣。若同時俄羅斯走第三羅馬、希臘走拜占庭、羅馬共和與軍團帝國也在利比亞存在，跳出【**至高羅馬最終對決**】機制 |
| E | 前面與 D 一樣，但法國與希臘雙方選擇議和，觸發【**第二次的查理曼與伊琳娜**】，兩國進行聯姻 |
| F | 前面與 D 一樣，拿破崙與哈布斯堡選擇聯姻 |
